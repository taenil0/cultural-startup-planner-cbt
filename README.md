## 🎯 주요 기능 및 특징

1. **💡 학습 모드 (Study Mode)**
   - 문제 풀이 즉시 정답/오답 피드백 제공
   - 출제위원의 실제 육성 멘트 기반 **출제 힌트** 수록
   - 문항별 상세 해설 및 오답 분석 제공

2. **⏱️ 실전 시험 모드 (Exam Mode)**
   - 실제 자격시험과 동일한 카운트다운 타이머 (과목별 25분 / 전과목 100분)
   - OMR 답안지 실시간 마킹 및 북마크, 미풀이 문항 필터링
   - 시험 종료 시 자동 채점 및 **합격/과락(과목당 40점 미만) 자동 판정**
   - 오답만 모아서 다시 푸는 **원클릭 오답노트** 지원

3. **🧮 3과목 전용 재무 계산기 내장**
   - BEP(손익분기점), Post-money 가치, 투자자 지분율, EBITDA 계산을 시험 화면 내에서 바로 수행 가능

4. **📄 과목별 워드(.docx) 시험지 제공**
   - MS Word 및 구글독스(Google Docs)에서 바로 열람·인쇄할 수 있는 고품질 문서 파일 내장
